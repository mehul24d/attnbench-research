## What runs

`python3 scripts/t61_session.py run --banked-at P1=<when P1 was banked>` on the instance from the repo root, after deploy, preflight, the GCS write gate and `scripts/gcp_bootstrap_instance.sh`. Each step runs in its own process through `scripts/run_phase.sh`, and the first failure stops the session. On Spot it runs in blocks (`--block`), each on its own boot, and an interrupted block's rows are discarded.

## Staged on the instance before `run`

- `p1_masks/`: P1's banked XAttention masks, copied from T3.2d's step 5 (`<cell>/recording/masks.{npz,json}` for every `xattention` and `xattention_noassert` cell), for the mask gate (T2.23).
- The P1 training file at `results/p1_training/p1_training.json.gz`, its sha256 the lock's.
- `docs/lock_values.json`, the tagged lock (T4.4). Without it the session's values and the mask-gate bound are unset, and the steps refuse.
- `--banked-at P1=<ISO time>`, the time P1 was banked.
