# T2.3 on the L4's recorded traces (10 Nov 2026)

Adviser's ruling 4 of the 10 Nov 2026 paste: a waiver is approved only for a
task that feeds no lock value, gate or committed prediction; otherwise the
task is done or flagged. T2.3's checker feeds H0 and H2 (which pairings
compare, Section 5.1) and the arms table's synchronisation column feeds H1's
arm classes. So it was run, not waived, on sequences already banked.

**Input.** T3.2d's banked sequences (identity `3c44588`, L4, 9 Nov 2026),
the 35 Gate A cells of five code paths: dense, oracle, mean-pool,
XAttention as shipped and XAttention with Python asserts removed (both on the
PyTorch path, `xattn:torch`). Each `sequence.json` was written on the L4 by
`op_sequence.parse_trace` from that session's profiler trace, with the GPU
stream ids. T3.2c's (identity `6c0326a`, 8 Nov 2026) are the earlier session
for the strict comparison. Both were pulled before this date (no bucket read
today).

    python3 -I scripts/t23_sync_report.py <T3.2d gatea> --against <T3.2c gatea>

The output is `docs/t23_l4_sync_20261110.json` (sha256 `4e562fe1…`).

## Results

- **Streams.** All 35 cells use one stream, with no cross-stream waits.
- **Strict "same sequence".** Each of the 35 is the same sequence as T3.2c's
  at its cell (identities `6c0326a` and `3c44588`).
- **Asserts.** At 2048 to 16384 tokens, the asserts-removed arm is the
  shipped arm with 2 asserts per layer removed, 56 in all: each is device
  work and one `bool` synchronisation. At 32768 the attribution is
  **refused**: the shipped arm has 17 synchronisations per layer and the
  stripped one 9, but the removed runs do not all have the form "device
  work, then one `bool`". Some carry an extra `fill_`; one is a lone `bool`.
  Nothing prices from this attribution (no session step calls it), so the
  refusal changes no number. It is a labelling limit, reported, not fixed.
- **Trace flags.** No implicit waits. Memsets with no device record: 28 in
  dense batch 4 at 16384, and 84 in every arm at 32768 (priced on the host
  only, Appendix A, 31 Oct 2026).

layer. That points to the shared selector or kernel path rather than to the
estimators, but it was not traced to its source.
