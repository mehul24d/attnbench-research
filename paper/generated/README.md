# Generated numbers

`numbers.tex` is written here by `scripts/paper_artifacts.py` (task C10, not
yet built). It defines one macro per number the paper prints. No number is
typed into the paper's text.

This path is a placeholder until C10 fixes where the script writes. The
Makefile takes the path as `NUMBERS=...`. If the file is missing, the build
stops with an error. There is no fallback value.
